# GTR Camera autonomous — simulator
**Goal:** Validate if camera only autonomous is realistic simulation

### Track guidance ###
1. To create a track, use components/track/data and either change the .txt file or make a new one
2. Then make the track: 
    - . is empty space
    - X tracks drivable area
    - S starting point
    - E ending point
3. update config.json to use the correct file
